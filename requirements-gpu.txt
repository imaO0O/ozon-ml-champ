# Нейросетевая половина решения. Отдельным файлом, потому что колесо torch
# ставится не с PyPI, а с индекса PyTorch под конкретную версию CUDA, и
# обычный `pip install -r` его оттуда не возьмёт.
#
# Бустинговая половина в этом файле НЕ нуждается: она считается на процессоре,
# и это не оговорка, а проверенный факт (docs/jury/A1_resources.md).
#
#     pip install torch==2.11.0 --index-url https://download.pytorch.org/whl/cu128
#
# Версия CUDA выбирается по видеокарте. Для 50-й серии (Blackwell, sm_120)
# нужен cu128 и новее: колёса под cu121 на такой карте не запускаются вовсе.
# Проверено на RTX 5070, драйвер 591.86, Windows 11.
#
torch==2.11.0+cu128
