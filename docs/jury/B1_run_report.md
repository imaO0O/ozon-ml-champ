## Два дефекта, найденных прогоном — статическим чтением не видны

**Оба починены в `main`.** Описание оставлено как есть — оно показывает, что
именно нашёл прогон на чистой машине; ниже по каждому указано, чем закрыт.

### 1. `predict.py` падает трейсбеком вместо своего же сообщения

Сценарий — самый частый у новичка: обучил без `--final`, пошёл делать сабмит.

```
$ python -u src/train.py --cutoffs 3 --rounds 100 --name nofinal
прогон без --final: веса не сохранялись
$ python -u src/predict.py --name nofinal
FileNotFoundError: models/nofinal_meta.json
```

В `predict.py` есть заготовленная вежливая проверка
(`модели '...' обучены без --final...`), но она **недостижима**: файл
`_meta.json` вообще не создаётся без `--final`, поэтому чтение падает
строкой выше. Лечится одной проверкой существования файла перед чтением.
Файл чужой, поэтому правка не вносилась — только зафиксирована.

### 2. `datasets.py --clean` всегда удаляет кэш с `--history`

`clean_stale_cache` решает, что оставить, по `p.stem.endswith(keep)`. У файлов
с обрезанной историей имя кончается на `_h180`, а не на хеш версии,
поэтому проверка не срабатывает никогда. Продемонстрировано на одной
и той же версии признаков `eea7602e`:

```
$ python -u src/datasets.py --cutoffs 1 --history 180 --clean
освобождено 2 МБ, оставлена версия eea7602e
[2026-01-15] 7,733 строк x 245 колонок — пересобран тем же запуском
```

Скрипт удалил свежий кэш и тут же его перестроил. На боевых данных
это не 2 МБ и полсекунды, а сотни мегабайт и минуты на каждый срез.
Затрагивает воспроизведение отрицательного результата про одинаковую глубину
истории (PLAN, раздел 4).

## Численная проверка ключевого утверждения B2

Утверждение «калибровка не меняет Gini» проверено на реальном векторе
предсказаний (7 887 значений, размах log1p от 0.221 до 8.329):

| поправка | порядок клиентов сохранён |
|---|---|
| сдвиг +0.0578 | да |
| растяжение 1.0545 | да |
| кривизна −0.01325 | да |
| все три подряд | да |

Производная поправки кривизны `1 + γ(2u − c)` при c = 1.9957 лежит
в диапазоне **от 0.8627 до 1.0775** — всюду положительна. Нуля она достигла
бы при u = 38.7, тогда как наблюдаемый максимум u = 6.18. Запас по
монотонности шестикратный, то есть утверждение верно не случайно, а с
большим запасом. На вопрос жюри «а вдруг квадратичная поправка портит
ранжирование» есть прямой численный ответ.
