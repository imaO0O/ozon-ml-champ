# C2. Вклад трека C: что принято и что закрыто

Все числа — выровненный RMSLE на валидации, три сида на руку, два среза
(2026-01-15 и 2025-12-16). Направление считается принятым только при
положительном знаке на обоих срезах.

## Принято

| что | январь | декабрь | где в коде |
|---|---|---|---|
| дневные ранги клиента внутри площадки | +0.00141 | +0.00129 | `seq_data.RANK_CHANNELS` |
| стекинг на двух сетях | +0.00059 | +0.00105 | `features/net.py`, `--net-names` |
| критерий остановки по выровненной метрике | +0.00112 | 0.00000 | `seq_train.train_model` |
| **плотное окно 365 дней** | **+0.00118** | **+0.00272** | `--lookback 365` |
| настройка бустинга заново | +0.00014 | +0.00120 | `lgb_grid.py` |

Дневные ранги подтверждены на **шести** срезах, не на двух: положительны
везде, среднее +0.00168, Gini растёт на всех шести.

Годовое окно — сильнейший результат работы. Оно единственное, чей выигрыш
состав не поглотил: все прочие улучшения давали составу 0.00002–0.00007,
годовое окно дало **+0.00083 и +0.00122** и стало главным участником с весом
0.44–0.68. Причина, по-видимому, в том, что длинная история несёт сигнал,
которого нет ни в девяноста днях, ни в стекинге на них.

## Закрыто, с механизмом

Восемь направлений. У каждого в коде оставлен модуль, воспроизводящий отказ,
и разбор причины — чтобы никто не проверял заново.

| направление | итог | причина |
|---|---|---|
| событийная последовательность | −0.0012 / −0.0018 | GRU принимает промежуток признаком, но не умеет затухать состоянием пропорционально ему |
| нормировка на собственную историю | −0.0087 | делитель оценён по разреженным данным одного клиента |
| деление цели на свой темп | −0.0103 | см. ниже, семейство |
| пулинг по когортам | −0.0131 | то же семейство |
| шесть дневных рангов вместо трёх | +0.00003, 2/6 | расщепление уже взятой величины новым взглядом не является |
| плотные срезы (шаг 15 и 7 дней) | монотонно хуже | таргет 30 дней, при меньшем шаге соседние срезы делят одни покупки |
| две головы у сети | −0.00005 | обе читают одно скрытое состояние; у бустинга это два разных обучения |
| длина расписания вне 8–16 | −0.0013 при 24 | оптимум плоский, умолчание уже в нём |

Три отказа из восьми объясняются одной причиной и закрывают **целое
семейство**: любая аддитивная база остатка. У 45.9% клиентов таргет ровно
ноль, а `log1p(0) = 0`, поэтому вычитание положительной базы даёт половине
выборки большой отрицательный остаток. Допустима только форма, взвешенная
вероятностью покупки, — а она у нас уже есть в двухголовой схеме бустинга.

## Правило, выведенное из принятого и закрытого

Сработали ровно те изменения, которые **добавляли уровнеустойчивый взгляд** на
уже имеющуюся величину: статические ранги, дневные ранги. Провалились все,
которые **убирали информацию** ради непохожести: события, нормировки, деления.
И расщепление уже взятой величины новым взглядом не является — шесть рангов
вместо трёх дали ноль.

## Инструменты, оставшиеся команде

`seq_blend.py --sweep` — точное решение оптимума состава: после выравнивания
`MSE(w) = w'Cw`, перебирать нечего, оптимум и цена отхода берутся формулой.

`seq_blend.py --gini-trade` — покупка Gini на плоскости весов. Жюри смотрит два
критерия, а кривая весов измеренно плоская; внутри запаса 0.0001 RMSLE можно
поднять Gini на 0.0004.

`seq_blend.py --compose-submissions` — сборка сабмита состава с выравниванием
уровня каждого участника до смешивания. Без этого веса, подобранные на
валидации, к сабмитам неприменимы.

`lgb_grid.py` — перебор гиперпараметров по выровненной метрике; печатает
лучшую по выровненной и лучшую по сырой отдельно и говорит, когда они
расходятся.
